# 保修服务：质保与维修

> 本文为合成客服语料，仅用于第二领域评测，不代表任何真实商家的政策。

## 1. 保修期

| 部件类型 | 保修期 |
| --- | --- |
| 主机 | 12个月 |
| 配件 | 6个月 |
| 耗材 | 3个月 |

保修期以签收日为准。购买延长保修服务后，主机保修期可再延长 12个月。

## 2. 保修范围

保修覆盖非人为原因导致的质量问题。以下情况不在保修范围：

- 进水、摔落、挤压等意外损坏；
- 私自拆修或改装；
- 超出保修期。

## 3. 维修流程

1. 在订单详情页提交维修申请；
2. 上传订单号、故障照片或视频、发票；
3. 客服在 1个工作日 内审核；
4. 审核通过后寄修或预约上门；
5. 维修周期为 3-7个工作日；
6. 维修完成后寄回，运费由商家承担。

## 4. 凭证要求

申请保修维修需要提供订单号、故障照片或视频，以及电子发票。电子发票可在订单完成后 24小时 内于订单详情页下载。

## 5. 维修期间权益

维修期间会员等级与积分保持不变；若维修超时，可联系客服申请运费补偿。
